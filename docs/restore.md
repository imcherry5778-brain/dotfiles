# 복구 계약

현재 저장소는 실제 사용자 설정을 적용하지 않으므로 되돌릴 사용자 설정 변경이 없다. 이 단계에서 홈 전체 백업이나 인증 데이터 복사를 만들지 않는다.

향후 이전은 관리 대상 파일별 제한된 복구본과 Git 기준을 준비한 뒤 진행한다. 이전 Git 기준으로 원본·검증한 설치 버전을 복구하고 실제 앱 동작을 확인한다.

로그인 상태·대화·사용자 파일·프로젝트 작업을 과거 시점으로 자동 되돌리지 않는다. 앱 설정 스키마와 OS 패키지 downgrade는 별도 확인이 필요하다. 자동 restore 작업은 이 계약을 실제로 검증한 뒤 구현한다.
