# 전역 mise source

config.toml에는 공통 13개, config.ai.toml에는 기존 OpenCode 1개, config.personal-fedora.toml에는 Fedora 기존 추가 20개를 선언했다. miserc.toml.tmpl은 명시적으로 선택한 기기 환경을 렌더링한다. root mise.toml의 저장소 작업과 책임이 다르다.

선언한 도구를 설치하거나 현재 RPM/수동 공급자를 전환하지 않았다. 버전은 확인된 Fedora 기준이며 lockfile과 다른 OS artifact 검증은 후속 단계다. 이 README는 홈에 배포하지 않는다.
